# bus-ticket-booking-system-c
C program to calculate bus ticket price and student discount using if-else conditions.


# Bus Ticket Booking System in C

This C program calculates:
- bus ticket price
- student discount
- final ticket amount

based on:
- age
- student status

using if-else conditions.

## Features
- Free ticket for kids under 5
- Student discount
- Multiple ticket pricing rules

## Concepts Used
- if-else
- logical operators
- user input
